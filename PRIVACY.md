# Privacy Policy for Recent Tabs Switcher

Last updated: September 3, 2026

Recent Tabs Switcher has one purpose: helping users find and switch among their open Chrome tabs in most-recently-used order.

## Data handled

The extension reads the titles, URLs, favicons, tab IDs, and window IDs of open tabs to display the switcher and activate or close the tab selected by the user. It stores only tab IDs in Chrome's session storage to maintain recent-tab order; Chrome clears this temporary data when the browser session ends. The extension stores the user's all-windows preference locally on their device.

## Data sharing and retention

Recent Tabs Switcher does not transmit data off the user's device. It has no server, analytics, advertising, tracking, account system, or third-party data sharing. It does not sell user data. No human reads user data handled by the extension.

The use of information received from Chrome APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.

## Permissions

- `tabs`: required to list open tabs and their titles, URLs, and favicons, and to activate or close the tab the user selects.
- `storage`: required to keep temporary most-recently-used ordering and the user's all-windows preference.
